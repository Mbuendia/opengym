Diseñado para un rendimiento impecable en cualquier dispositivo

Instálalo como PWA en iOS o Android, usa el modo mantenido de pantalla (*Wake Lock*) durante tu sesión y accede a tus estadísticas históricas en milisegundos.

🔒 WebAuthn Passkeys ⚡ Docker Ready

Todo lo que necesitas para tu entrenamiento

Potente, ligero y totalmente bajo tu control.

🔒

Passkeys (WebAuthn)

Olvídate de las contraseñas tradicionales. Inicia sesión al instante con la huella dactilar, Face ID o PIN de tu dispositivo de forma criptográfica.

🏋️‍♂️

Series, Repes & Superseries

Soporte completo para ejercicios de fuerza, peso corporal, cardio y superseries combinadas con temporizador de descanso automatizado.

📊

Estimación 1RM & Progreso

Calcula automáticamente tu repetición máxima (1RM), analiza gráficos de volumen de carga e historial de peso corporal por fechas.

🛡️

Soberanía de Datos

Tus datos se guardan en archivos JSON ligeros. Exporta o haz copias de seguridad de todo tu historial con 1 solo clic cuando quieras.

📱

PWA Instalable & Offline

Agrégalo a la pantalla de inicio de tu teléfono. Funciona sin conexión y mantiene la pantalla encendida mientras entrenas.

🌍

Multidioma Nativo

Traducido completamente al Español, Inglés, Francés, Alemán, Ruso, Chino, Portugués y más idiomas.

Despliega tu propio servidor en segundos

Ejecuta tu instancia privada en Docker o Render.

# 1. Clona el repositorio oficial
git clone https://github.com/Mbuendia/opengym.git
cd opengym

# 2. Despliega con Docker Compose en tu servidor local
docker compose up -d

# ¡Listo! Abre http://localhost:8080 en tu navegador
